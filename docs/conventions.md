# Naming conventions

ArchGrader grades **results, not code**. Every assignment tells students to
save its key answers under fixed object names, and the grader inspects those
objects. Checking an object is easy and robust; parsing arbitrary R code is
neither. The same names appear in the assignment, the instructor solution, and
the rubric.

## Why named objects

- A student can compute the same mean with base R, `dplyr`, or `aggregate()`,
  and all three pass, because only the resulting object is compared.
- A missing object scores zero for that criterion, and the feedback hint names
  the object the student should have created.
- **Tradeoff:** students must follow the naming. Real courses do this with
  templates.

## Rules for every assignment

1. Each task names the object to create, in **bold code** in the task text.
2. Names are `snake_case` and descriptive (`mean_length`, not `m`).
3. Object type and column names are stated in the task (for example "a data
   frame with columns `site` and `median_length`").
4. Chunk labels are written in the header style, ` ```{r label} `, and
   students must not rename them. The header style matters: `knitr::purl()`
   keeps these labels in its output, but drops labels given as `#| label:`
   options, and the runner relies on labels to point at the failing chunk.
5. The data file is read from the working directory as `artifacts.csv`.
6. Assignments use a fixed seed wherever randomness appears, and numeric
   comparisons use tolerances set in the rubric.

## Assignment 1: summary statistics (`inst/assignments/a1.qmd`)

| Object | Type | Task |
|---|---|---|
| `mean_length` | number | Overall mean of `length_mm` |
| `sd_length` | number | Overall standard deviation of `length_mm` |
| `median_by_site` | data frame: `site`, `median_length` | Median `length_mm` per site |
| `count_by_material` | data frame: `raw_material`, `n` | Artifact count per raw material |
| `summary_table` | data frame: `site`, `n`, `mean_length`, `sd_length` | Per-site summary |

Chunk labels: `load-data`, `overall-stats`, `median-by-site`,
`count-by-material`, `summary-table`.

## Assignment 2: data visualization (`inst/assignments/a2.qmd`)

| Object | Type | Task |
|---|---|---|
| `length_width_plot` | ggplot | Scatter plot of `length_mm` (x) against `width_mm` (y), points coloured by `raw_material`, with descriptive axis labels and a title |

Chunk labels: `load-data` (which also calls `library(ggplot2)`), `scatter-plot`.
Students assign the plot with `<-`; auto-printing is not enough, because the
grader inspects the saved object.

## Assignment 3: statistical reasoning (`inst/assignments/a3.qmd`)

The task compares River Terrace with Cave Mouth. `load-data` also creates
`two_sites`, the subset of `artifacts` for those two sites.

| Object | Type | Task |
|---|---|---|
| `t_statistic` | number | Test statistic for the difference in mean `length_mm` |
| `p_value` | number | p-value of the same test |
| `conf_int` | numeric vector, length 2 | 95% confidence interval for the difference (lower, upper) |
| `cohens_d` | number | Effect size |

Chunk labels: `load-data`, `run-test`, `effect-size`.

The written answer goes under a heading named exactly `## Interpretation`.
**Rule for any text-checked section:** the section must be empty apart from a
placeholder line in the template. If the instructions that sit under the
heading mention the keywords the rubric looks for, an empty answer would earn
credit. In A3 the instructions live in a separate "Task 3" section for this
reason (see the disagreement log).

## The dataset (`inst/assignments/artifacts.csv`)

150 synthetic artifacts, generated by `data-raw/artifacts.R` with a fixed seed.

| Column | Meaning |
|---|---|
| `artifact_id` | Unique label (`A001` to `A150`) |
| `site` | Ridge Camp, River Terrace, Cave Mouth, or Hilltop |
| `raw_material` | chert, obsidian, quartzite, or basalt |
| `length_mm`, `width_mm`, `thickness_mm` | Measurements, one decimal place |

The data are synthetic, so there are no licensing questions and the right
answer is known. Site means differ on purpose, so Assignment 3 has a real
effect to find.
